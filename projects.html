Projects

Projects in applied mathematics, statistical learning, and data analysis.

Cross-sectional return prediction

Personal project, 2026 · Code

A monthly stock-return prediction pipeline using CRSP data, ridge regression, and expanding-window validation. After correcting look-ahead bias, the predictive signal was weak and did not survive transaction costs.

Financial fraud detection

Team project, The Erdős Institute, 2026 · Code

A comparison of tabular models and graph neural networks for detecting illicit Bitcoin transactions in Elliptic and Elliptic++. Models are evaluated using chronological training, validation, and test splits.
